# 公共组件目录

本目录从 M02 开始按模块逐个实现公共组件。规划组件包括：

- `holland-hexagon`：霍兰德六边形及六维数据展示。
- `radar-chart`：结果雷达图，输入仅为六维标准化分数。
- `riasec-type-card`：六种类型统一卡片。
- `assessment-progress`：答题进度和已答数量。
- `report-section`：深度报告章节容器。
- `career-card`：职业和岗位摘要卡片。
- `case-card`：带来源信息的人物案例卡片。
- `empty-state`：空数据和异常状态。

M01 不创建空壳组件，避免未使用代码进入小程序包。
