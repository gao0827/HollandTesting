# 职趣测评

一个不依赖后台的微信原生小程序，用于完成霍兰德 RIASEC 职业兴趣自我探索。

## 已实现

- 标准版 60 道自编体验题，每个 RIASEC 维度 10 道
- 专业版 250 题，包括职业兴趣 60 题、技能自评 50 题、职业价值观 50 题、工作环境偏好 45 题和职业愿望 45 题
- 1–5 级兴趣作答与自动保存草稿
- R、I、A、S、E、C 六维计分和归一化展示
- 三字母 Holland Code、类型解释、优势和可探索领域
- 职业知识库、高中生与大学生、职场新人、职场转型人群及家长与职业辅导者的报告，含 90／180 天行动路线
- 按身份续答、本机报告保存、历史记录与数据清除
- 答题、计分和免费基础结果在本机完成，商业化接入见 [报告商业化配置](docs/report-monetization.md)

## 运行

1. 使用微信开发者工具导入本目录。
2. 测试阶段可使用 `touristappid`；发布前请在 `project.config.json` 中替换为正式小程序 AppID。
3. 直接编译运行，无需安装 npm 依赖。

## 数据说明

测评结果保存在微信客户端本地存储中，最多保留最近 30 次。该工具用于兴趣探索，不构成职业、心理或医学诊断。

专业版附加部分各自计分。技能自评允许选择「未尝试或无法判断」，这类回答保留在本地答卷中，并从熟练度均值中排除。专业版题目为项目自编，当前用于职业探索，尚未经正式信效度验证。

## 测试与发布检查

运行 `node --test tests/*.test.js` 执行回归，运行 `node scripts/check-release.js` 检查当前配置。正式提审步骤见 [M12 发布清单](docs/M12-release.md)。现有版本使用体验 AppID，正式 AppID 由项目负责人配置。
