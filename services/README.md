# 服务层目录

服务层用于隔离页面与数据来源、存储实现和商业能力。规划服务见 `docs/M01-architecture.md`。

开发约束：

- 页面不直接实现评分规则。
- 题库读取必须携带题库 ID 和版本。
- 本地存储必须通过统一服务处理迁移和异常。
- 报告服务只消费已完成的测评记录。
- 商业服务默认关闭，不能返回模拟支付成功。
- 每个服务在首次接入页面前必须有对应单元测试。

M11 的商业接口位于 `commercial-service.js`。广告展示、下单、支付、订单校验、付费解锁和退款均保留为异步接口。当前调用会返回明确的不可用错误。

接入正式提供方后，支付状态、退款状态和报告权益应由服务端确认。微信客户端回调仅用于提示和刷新订单状态。正式付费报告使用独立的 `paidReportUnlock` 开关，现有本地报告仍由 `deepReport` 控制。
